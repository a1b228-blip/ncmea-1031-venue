# 1031 情境模擬競賽｜場地配置與急救預案

NCMEA 國家臨床醫學教育獎 擬真情境類競賽・醫事放射組第二場（2026/10/31，林口長庚）備賽網頁。

**線上瀏覽：** https://a1b228-blip.github.io/ncmea-1031-venue/

## 分頁
- **靜態圖**：考場 3D 配置圖（方案一 A＝X 光／B＝CT；方案二 A＝CT／B＝X 光）
- **互動 3D**：可旋轉、縮放、平移的考場模型
- **林口場地結合**：林口長庚場地 3D／2D 平面圖與考場配置圖的對應
- **考前重點提醒**：參賽注意事項重點整理、控制台螢幕說明
- **急救情境預案**：四種急救狀況的人力與急救設備調度示意圖

## 本機預覽
```
python3 serve.py 8767
```
然後開啟 http://localhost:8767（3D 頁面需要透過網頁伺服器開啟）。
